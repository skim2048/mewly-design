구조 지도 — 화면·API·토큰

반려견 건강 관리 AI 펫하우스. Vue 3 + Capacitor 프론트엔드(mewly)와 Jetson 위에서 도는 4컨테이너 VLM 백엔드(babycat)를 한 장으로 대조한다. 아래 지도가 앞으로의 동기화 기준점이 된다.

01

두 리포지토리의 경계

mewly — 프론트엔드

Vue 3.5 + vue-router 4 + Vite 6, Capacitor 7로 안드로이드 패키징. hls.js 외 UI 라이브러리 없음 — 컴포넌트·CSS 전부 자작.

24 components 24 composables 2 views

의미 결정권을 전부 쥔다. 라벨 어휘·프리셋·기준선·리듬 카드 판정 — 백엔드는 이 중 어느 것의 의미도 모른다.

babycat — 백엔드

Python + FastAPI + GStreamer, Docker Compose 4컨테이너. NVIDIA Jetson Orin, VILA1.5-3b 추론. UI 없음 — HTTP API만 노출.

router인증·토큰·중계·SSE 병합. 유일한 외부 진입점
streamer카메라 프로필·ONVIF PTZ·HLS/WebRTC 재배포
analyzerVLM 추론·키워드 매치·이벤트 통지
recorder클립 조립·이벤트/추론 이력·집계·하드웨어 상태

8000/tcp HTTPS 게이트웨이(사설 CA) 단일 진입, 8189/udp WebRTC 미디어만 우회.

05

진단

코드에서 실제로 확인한 것만 적었다. 위에서부터 영향이 큰 순서.

결함 타입 스케일 토큰 두 개가 폰트 스택에 덮여 무효화됨

global.css의 :root는 타입 스케일에서 --font-body: 14px · --font-heading: 18px를 정의하지만, 같은 블록 아래쪽 Typography 절에서 같은 이름을 폰트 패밀리로 재정의한다. CSS는 나중 선언이 이기므로 두 변수의 최종 값은 'NanumSquare', 'Inter', system-ui, sans-serif다.

--font-body: 14px; /* 타입 스케일 */
…
--font-body: 'NanumSquare', 'Inter', system-ui, sans-serif; /* 최종 승자 */
font-size: var(--font-body) → invalid, 선언 버려짐

결과적으로 font-size: var(--font-body)와 var(--font-heading)를 쓴 모든 선언이 파싱 단계에서 버려지고 상속값(브라우저 기본 16px)이 그대로 내려온다. .app-frame·.topbar-title·.btn·.form-field·.chip-btn·.toast-text 등 본문 어법 전체가 해당된다 — 의도한 14px 대신 16px, 화면 제목은 18px 대신 굵기만 다른 16px. --font-caption/label/title은 충돌이 없어 정상이므로, 5단 스케일 중 3단만 살아 있고 위계가 부분적으로 무너진 상태다.

고치는 법: 폰트 패밀리 쪽 이름을 --font-family-body · --font-family-heading으로 분리. --font-ui·--font-heading-weight 참조처도 함께 정리해야 한다.

구조 기능 절반이 서버 없이 localStorage 위에 서 있다

일정·알림·알림 설정·기기 제어(마이크/온도/조명) 5종은 형태만 구현된 목업이다. babycat이 지원하지 않아 컴포저블 내부를 localStorage로 구동하고 인터페이스만 도출해 둔 상태 — 의도된 설계이고 프로필은 이미 /client/storage/pet_profile로 서버 이전됐다. 다만 사용자 눈에는 진짜 기능과 구분되지 않는다: 기기 제어 실패 토스트는 목업이라 아예 발화하지 않고, 일정 알람은 앱이 꺼져 있으면 울리지 않는다. 디자인상 "아직 연결 안 됨"을 드러낼지 숨길지가 미결이다.

구조 거대 컴포넌트 3종

HomeTab 44KB · AnalysisTab 34KB · PtzSheet 25KB — 세 파일이 소스의 큰 몫을 차지한다. HomeTab 하나가 영상 플레이어·프로토콜 전환·기기 버튼·VLM 아코디언·추론 로그·요약 대시보드·회전 전체화면을 전부 안는다. 디자인을 손볼 때 영향 범위를 읽기 어려운 지점이고, 화면 단위로 리디자인하려면 여기부터 갈라야 한다.

명명 /state와 /events가 이름으로 서로를 가린다

프론트의 APP_ENDPOINTS.events는 실제로 /state(라이브 SSE)를 가리키고, 저장된 이벤트 이력은 API_ENDPOINTS.eventHistory → /events다. 코드 주석이 이 함정을 명시해 두었을 만큼 반복해서 걸리는 지점 — 이름을 liveState로 바꾸면 주석 없이도 읽힌다.

기회 추론 원문이 90일치 쌓이는데 열람 경로가 없다

recorder는 매치 여부와 무관하게 VLM 서술 원문(vlm_text)을 전량 보존하고 GET /inferences로 질의를 열어 두었다. 프론트는 집계된 /summary만 소비하므로 "그때 실제로 뭘 봤는지"를 보호자가 읽을 방법이 없다. 리듬 카드가 "평소보다 오래 누워 있었어요"라고 말할 때 그 근거 문장을 펼쳐 보이는 것은 곧바로 만들 수 있는 신뢰 장치다.
